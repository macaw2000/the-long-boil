# The cast

Source: `docs/gdd.md`, section 3.

An agent writing a character may use only what that character **knows**. The **hides** column is the writer's context, not the character's dialogue: it says what they will steer away from, never what they will admit. A character never states a fact from a reveal layer above the act being written.
