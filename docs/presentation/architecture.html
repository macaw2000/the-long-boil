Application Load Balancer

ECS Fargate · Graviton (ARM)

The game server

Node.js 22, TypeScript, Fastify. The authoritative rules engine: idle work resolved offline, combat, drops, the Exchange order book, the story engine, guilds, chat, the Cog Shop.

Every change is an event in an ordered log, with seeded randomness, so any result can be replayed.

GitHub Actions

CI and deploy
